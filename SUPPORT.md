# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/universal-artifact-sdk/issues)
to track bugs and feature requests. Please search the existing issues before filing new
issues to avoid duplicates. For new issues, file your bug or feature request as a new
issue.

For help and questions about using this project, please open a
[GitHub Issue](https://github.com/microsoft/universal-artifact-sdk/issues) or start a
discussion in the repository.

## Microsoft Support Policy

Support for this project is limited to the resources listed above. This project is
provided as-is and is maintained on a best-effort basis by the maintainers and the
community.
